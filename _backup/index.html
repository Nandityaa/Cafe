    About Me

    Hai,I'm Nafa

    Hai, nama lengkap saya Gede Nafa Nanditya Aristyogi, kalian bisa memanggil saya Nafa atau Napa. Sekarang saya sedang belajar di SMK TI Bali Global Denpasar, jurusan RPL (Rekayasa Perangkat Lunak), dan fokus mempelajari pemrograman web, aplikasi, dan game.

    Saya tertarik dengan pengembangan web dan aplikasi, terutama menggunakan HTML, CSS, dan JavaScript. Saat ini saya sedang mengerjakan beberapa proyek web, seperti membuat portofolio digital dan situs web interaktif untuk tugas sekolah, Anda dapat melihat lebih lanjut project

    Di luar belajar, saya suka mendengarkan musik, terutama hip-hop. Bahkan ketika saya sedang berada di gym, saya sering mendengarkan musik untuk menambah semangat. Di masa depan, saya ingin magang di perusahaan teknologi agar saya dapat mengasah kemampuan saya lebih lanjut dan mempersiapkan diri untuk berkarir di bidang IT..
